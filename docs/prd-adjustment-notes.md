# PRD 调整备忘：从个人 Wiki 转向 Agent 名片与价值连接

## 1. 背景结论

当前 PRD 的主叙事是“公开链接素材 → 个人 Wiki → AI 名片 → 搜索推荐 → 连接”。这个方向作为长期产品架构是成立的，但不适合作为当前 MVP 的用户侧主叙事。

会议讨论后，当前 MVP 更应该聚焦：

```text
快速生成我的数字分身
→ 形成高级感 AI 名片
→ 让我能被别人快速理解
→ 帮我找到值得认识的人
→ 生成破冰和连接动作
```

因此，PRD 需要从“个人 Wiki 产品”调整为“AI Agent 名片 + 价值连接产品”。Wiki 可以继续保留为底层资料层，不应成为用户第一感知。

## 2. 产品定位调整

### 2.1 当前定位问题

当前定位偏向：

```text
Livelink 是一个 AI 个人 Wiki 与主动社交产品。
```

这个表达的问题：

- “个人 Wiki”对用户吸引力不够直接。
- 用户不一定有动力维护 Wiki。
- 路演和 Demo 场景下，听众更关心“它能帮我认识谁”。
- 当前黑客松 / 创业场景更需要快速展示个人价值和找人。

### 2.2 建议新定位

建议改为：

```text
Livelink 是一个 AI 数字分身与价值连接工具。
用户通过一段自我介绍、简历或公开链接生成自己的 Agent 名片，
让别人快速理解自己是谁、能提供什么、正在寻找什么，
并由 Agent 帮助发现匹配的人、生成推荐理由和破冰话术。
```

### 2.3 一句话描述建议

建议从：

```text
把你的公开链接素材整理成个人 Wiki，再生成一张可分享、可搜索、可推荐、可连接的 AI 名片。
```

调整为：

```text
用 AI 生成你的数字分身名片，帮你展示价值、发现合适的人，并更自然地发起连接。
```

或更路演化：

```text
先让 AI 讲清楚“我是谁”，再让 Agent 帮我找到“我该认识谁”。
```

## 3. MVP 主闭环调整

### 3.1 当前主闭环

当前 PRD 主闭环偏长：

```text
用户输入基础资料并粘贴公开链接
→ 系统抓取和清洗链接素材
→ AI 抽取事实、项目、技能、话题和需求
→ 生成结构化个人知识库
→ 生成个人 Wiki
→ 从 Wiki 派生 AI 名片
→ 用户编辑确认并发布
→ 他人浏览 / 扫码访问 / 搜索 / 推荐发现
→ 发起连接
→ 沉淀关系记录
```

问题：

- 链路太长。
- 公开链接抓取风险高。
- Wiki 不是当前最有展示力的页面。
- 找人和破冰价值出现太晚。

### 3.2 建议新主闭环

建议改为：

```text
用户进入首页
→ 输入自我介绍 / 上传简历 / 粘贴公开链接
→ AI 生成 Agent Profile
→ 用户编辑确认 AI 名片
→ 生成公开主页、二维码和分享海报
→ 用户输入找人需求
→ Agent 推荐候选人并解释匹配理由
→ 用户查看候选人详情
→ Agent 生成破冰话术
→ 用户发起连接或复制文案外部联系
```

### 3.3 MVP 第一价值闭环

第一闭环应该是：

```text
从 C 到 A：真实用户 → AI 数字分身 / AI 名片
```

验收标准：

- 用户能低门槛生成自己的 Agent。
- 页面看起来有高级感。
- 用户觉得 AI 对自己的提炼“有点懂我”。
- 用户愿意分享这个页面或二维码。

### 3.4 MVP 第二价值闭环

第二闭环应该是：

```text
从 A 到人：Agent 帮用户发现值得认识的人
```

验收标准：

- 用户能输入“我想找什么人”。
- 系统返回候选人卡片。
- 每张卡片有匹配理由。
- 用户能进入详情页并生成破冰话术。

### 3.5 MVP 第三价值闭环

第三闭环应该是：

```text
从连接意图到破冰动作
```

验收标准：

- 对已有 Agent 的人，展示双方匹配上下文。
- 对未入驻的人，生成可复制到微信、社媒私信或评论区的破冰文案。
- 文案附带自己的 Agent 名片链接。

## 4. 目标用户调整

### 4.1 当前目标用户过宽

当前目标用户包括创业者、开发者、创作者、学生、HR、投资人、活动参与者等。作为长期方向可以保留，但 MVP 应该更聚焦。

### 4.2 建议 MVP 目标用户

建议 MVP 明确聚焦以下人群：

1. **黑客松参与者**
   - 目标：找队友、找技术伙伴、找设计师、找产品合伙人。
   - 价值：活动现场高频需要“快速理解彼此”。

2. **创业者 / 独立开发者**
   - 目标：找合伙人、找投资人、找资源、找早期用户。
   - 价值：需要展示自己和项目的价值。

3. **投资人 / 嘉宾 / 行业资源方**
   - 目标：发现有潜力的人和项目。
   - 价值：快速筛选和理解人。

4. **HR / 猎头 / 招聘方**
   - 目标：找候选人。
   - 价值：不只看简历，也看项目、动机、资源和表达方式。

### 4.3 暂不主打的人群

以下人群可以后续扩展，但不建议 MVP 主打：

- 泛社交用户。
- 相亲交友用户。
- 纯兴趣社区用户。
- 没有明确找人需求的普通名片用户。

## 5. 页面结构调整

### 5.1 首页

当前首页不应强调“生成个人 Wiki”，建议强调：

- 生成我的 AI Agent。
- 用一分钟讲清楚我是谁。
- 让别人快速理解我的价值。
- 帮我找到合适的队友、投资人或合作对象。

首页 CTA 建议：

- `生成我的 Agent`
- `上传简历生成名片`
- `用一段介绍生成名片`
- `看看我能匹配谁`

### 5.2 Agent 生成页

应从“公开链接提交页”调整为“多输入 Agent 生成页”。

输入优先级：

1. 一段自我介绍。
2. 上传简历或粘贴简历文本。
3. 我能提供什么。
4. 我正在寻找什么。
5. 我的社交风格。
6. 公开链接。

引导问题建议：

- 你现在是谁？正在做什么？
- 你做过哪些值得介绍的项目？
- 你擅长什么？
- 你能为别人提供什么？
- 你现在最想认识什么样的人？
- 你希望别人如何感知你？

### 5.3 Agent 详情页 / AI 名片页

这是 MVP 核心展示页，应优先于 Wiki 页面。

建议结构：

```text
首屏：
- 头像 / 名字 / 当前身份
- 一句话定位
- 3-5 个社交货币标签
- 主要 CTA：分享 / 找人 / 完善我的 Agent

主体：
- AI 对我的洞察
- 履历和项目亮点
- 我能提供
- 我正在寻找
- 适合和我聊什么
- 我的社交风格 / Soul

底部：
- 二维码 / 分享入口
- 生成海报
- 继续完善资料
```

### 5.4 分享海报页

分享海报应进入 MVP，而不是后续附属功能。

海报内容：

- 姓名。
- 一句话定位。
- 关键标签。
- 代表性亮点。
- 二维码。
- 简短引导语。

设计要求：

- 高级感。
- 适合微信分享。
- 不要幼稚风。
- 有一定炫耀感，但不能夸张造假。

### 5.5 找人发现页

应从“搜索页”调整为“推荐市场 / 找人页”。

用户输入：

- 我想找什么人。
- 用于什么场景。
- 我能提供什么交换价值。

候选人卡片展示：

- 姓名 / 身份。
- 标签。
- 一句话介绍。
- 匹配分。
- 匹配理由。
- 建议连接方式。

### 5.6 候选人详情页

新增或强化候选人详情页。

内容：

- 候选人的 Agent 摘要。
- 为什么推荐给我。
- 我们可能合作什么。
- 我可以向他请求什么。
- 对方可能关心我的什么。
- 推荐破冰点。

CTA：

- `生成破冰话术`
- `发起连接`
- `复制联系文案`
- `分享我的名片给他`

### 5.7 连接页 / 破冰页

连接页不只是一个留言框，而是“预沟通和破冰辅助页”。

两种状态：

1. **对方已有 Agent**
   - 展示双方 Agent 的预匹配摘要。
   - 展示可聊话题。
   - 展示连接建议。

2. **对方没有 Agent**
   - 展示基于公开信息生成的临时摘要。
   - 生成可复制的社媒 / 微信破冰文案。
   - 附带我的 Agent 名片链接。
   - 引导对方生成自己的 Agent。

## 6. 功能优先级调整

### 6.1 当前优先级问题

当前优先级偏向：

```text
公开链接抓取
→ 知识抽取
→ Wiki 生成
→ 名片生成
→ 搜索
→ 推荐
→ 连接
```

问题：

- 最有演示价值的“推荐”和“破冰”出现太晚。
- “简历 / 自我介绍”被后置。
- “海报分享”不够突出。

### 6.2 建议新优先级

建议调整为：

```text
P0：Agent 生成主链路
P0：AI 名片展示页
P0：编辑确认和发布
P1：分享海报和二维码
P1：找人需求输入
P1：推荐候选人卡片
P1：匹配理由
P2：候选人详情页
P2：破冰话术生成
P2：连接请求记录
P3：Wiki 深度页
P3：完整搜索
P4：真实社媒抓取和 Agent-to-Agent
```

## 7. 输入策略调整

### 7.1 当前问题

如果一开始要求用户粘贴多个公开链接或授权多个账号，门槛偏高。

### 7.2 建议输入策略

采用“低门槛进入 + 渐进完善”：

```text
第一步：手机号 / 昵称 / 当前身份
第二步：一段自我介绍或简历
第三步：我能提供 + 我想找什么
第四步：生成初版 Agent
第五步：提示继续补充公开链接和社媒
```

### 7.3 完善激励

提示逻辑：

- 信息越完整，匹配越精准。
- 想认识更高价值的人，需要先展示自己的价值。
- 如果匹配不到合适的人，引导用户完善 Agent。

示例提示：

```text
你的 Agent 当前理解度为 42%。补充项目经历和找人需求后，可以获得更准确的推荐。
```

## 8. AI 生成内容要求

### 8.1 内容目标

AI 生成内容要同时服务：

1. 给人看。
2. 给推荐匹配系统看。
3. 给破冰连接场景使用。

### 8.2 风格要求

AI 输出应遵循：

- 真实，不夸大。
- 有高级感。
- 不要简历腔。
- 不要营销号腔。
- 能让别人快速判断“是否值得认识”。
- 可以有轻微炫耀感，但必须有事实支撑。

### 8.3 必须生成的内容块

Agent Profile 至少应包含：

- 一句话定位。
- 简短 Bio。
- 社交货币标签。
- 核心技能。
- 履历 / 项目亮点。
- AI 洞察。
- 我能提供。
- 我正在寻找。
- 适合和我聊的话题。
- 破冰建议。

## 9. 推荐匹配逻辑调整

### 9.1 当前搜索逻辑不足

单纯搜索技能、标签、关键词不足以体现产品差异。

### 9.2 推荐逻辑应强调匹配理由

推荐结果必须解释：

- 为什么这个人适合你。
- 你们有什么互补点。
- 你可以向对方请求什么。
- 你能给对方什么价值。
- 适合用什么话题破冰。

### 9.3 MVP 推荐可以使用规则 + Mock

不需要一开始做复杂算法。

候选池来源：

- 预置嘉宾。
- 预置投资人。
- 预置创业者。
- 预置工程师 / 设计师 / 产品。
- 已生成 Agent 的用户。

匹配规则：

- `wants` 命中对方 `offers`。
- `offers` 命中对方 `wants`。
- 共同行业 / 技术方向。
- 当前场景一致，如黑客松。
- 城市或活动上下文一致。
- 用户信息完整度足够。

## 10. 连接逻辑调整

### 10.1 连接不是简单留言

连接页应该帮助用户完成：

- 理解对方。
- 理解为什么要认识。
- 组织自我介绍。
- 生成自然的开场。
- 附带自己的 Agent 名片。

### 10.2 对方已有 Agent

流程：

```text
用户点击候选人
→ 系统生成双方匹配上下文
→ 展示可能合作点
→ 生成破冰建议
→ 用户确认后发起连接
```

### 10.3 对方没有 Agent

流程：

```text
系统基于公开信息生成临时卡片
→ 用户复制破冰文案
→ 文案附带自己的 Agent 链接
→ 对方点击后了解用户
→ 引导对方生成自己的 Agent
```

## 11. Demo 和路演策略调整

### 11.1 Demo 不应追求完整真实系统

当前时间有限，Demo 应优先展示完整故事链路。

### 11.2 建议 Demo 脚本

```text
1. 我进入 Livelink。
2. 我用一段自我介绍生成 Agent。
3. AI 立刻提炼出我的身份、优势、资源和需求。
4. 我得到一张高级感 AI 名片和分享海报。
5. 我输入“我想找一个硬件工程师 / 投资人 / 设计师”。
6. Agent 推荐几个人，并说明为什么匹配。
7. 我点击其中一位，看到合作可能性。
8. Agent 帮我生成一段自然的破冰话术。
9. 我可以复制给对方，或者发起连接。
```

### 11.3 预置数据策略

建议提前准备：

- 10-20 个候选人 Profile。
- 3-5 个投资人。
- 3-5 个工程师。
- 3-5 个设计 / 产品 / 增长角色。
- 3-5 个创业者或嘉宾。

每个人需要：

- 名字。
- 身份。
- 标签。
- Bio。
- Offers。
- Wants。
- Demo 匹配理由。

## 12. 暂时后置的 PRD 内容

以下内容可以保留为长期方向，但不建议作为当前 MVP 必做：

- 完整个人 Wiki。
- 个人 Wiki 长文编辑器。
- 多来源自动抓取。
- 小红书 / B站 / GitHub 实时同步。
- 复杂搜索。
- 向量检索。
- 真实 Agent-to-Agent 自主对话。
- 认领未授权 Agent。
- 多级隐私权限。
- 关系管理 CRM。
- LBS 和活动地图。
- 泛社交推荐流。

## 14. 推荐新版 PRD 摘要

可以将 PRD 摘要调整为：

```text
Livelink 是一个面向创业、招聘和高价值社交场景的 AI 数字分身工具。
用户通过一段自我介绍、简历或公开链接生成自己的 Agent Profile。
这个 Profile 不只是静态名片，而是能表达用户的身份、能力、资源、需求和社交风格。
用户可以将它作为高级感 AI 名片分享出去，也可以让 Agent 基于自己的需求推荐值得认识的人。
当用户想连接某个人时，Agent 会生成匹配理由、上下文摘要和自然的破冰话术，帮助用户更高效地建立连接。
```
